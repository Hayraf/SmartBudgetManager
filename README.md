# SmartBudgetManager
A project for managing Budget.
Author: HAYANI Acheraf – Group 11 · 2nd year CPI, ESI-SBA 2026/2027
What it does
Saves your income and expenses
Puts expenses in 5 categories: Food, Transport, Rent, Health, Education
Calculates total income, total expenses, and your balance by itself
Shows a pie chart of your expenses
Shows OVER BUDGET (red) or WITHIN BUDGET (green)
What you need
Excel 2016, 2019, 2021, Microsoft 365, or LibreOffice Calc
SmartBudget_Manager.xlsx
No internet and no macros
How to start
1. SmartBudget_Manager.xlsx. If you see "Protected View", click Enable Editing.
2. In the Categories tab, set a Monthly Budget for each category.
3. In the Transactions tab, use the first empty row. Fill in Date, Description, Type, Category (expenses
only), and the amount in Income or Expense.
4. Open the Dashboard tab to see your totals, status, and chart.
The three sheets
| Sheet | What it is for | Do you type here? |
| Dashboard | Totals, status, chart | No |
| Transactions | Your income and expenses | Yes |
| Categories | Categories and budgets | Only the Monthly Budget column |
Rules
Never type in the Month column or on the Dashboard (formulas).
Pick the category from the list. Do not type it.
Use one file per month.
Limits
Only 47 transactions are counted (rows 4 to 50).
The warning checks the total budget, not each category.
The 5 categories are fixed.
Sheets are not protected by default (see the user guide, section 9).
